# CCEeXAM Simulator — ICU O.Dakka

460 questions for the NBE CCEeXAM, ordered by the NBE blueprint (D1 TTE/TEE 50%, D2 Physics 25%, D3 Other applications 25%).

- 460 questions grouped into 16 blueprint topics; start any topic directly or build a mixed session

Features: tutor and timed exam modes, question-count picker, difficulty/source/status filters, per-topic accuracy, mastery levels, streaks, weak-topic practice, flags, dark/light theme, installable PWA (works offline after first load).

## Deploy on GitHub Pages
1. Create a repo (e.g. `cceexam-simulator`) and upload the contents of this folder.
2. Settings → Pages → Source: `main` branch, `/ (root)`.
3. Open `https://<username>.github.io/cceexam-simulator/`.

Progress is stored in the browser (localStorage).
